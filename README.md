# AI-Card-Catcher

**把 AI 角色聊天网站的「人物卡 / 世界书 / 破甲提示词」完整抓下来的本地工具。**

你现在用的某个 AI 角色扮演网站，每次对话时都会把**角色的全部设定**（人物卡、世界书、越狱提示词、聊天历史，动辄几十 KB 甚至几百 KB）作为请求发给大模型 API。本工具在你的电脑上扮演一个「中间人」：让网站的 API 流量经过你，把设定原样记录下来，并自动分类整理成可下载的 JSON。

> ⚠️ **免责声明**：仅用于提取**你自己有权访问**的角色内容与个人备份。使用请遵守相关网站的服务条款与法律法规，勿用于侵犯他人权益或商业用途。

## 它是怎么工作的

```
AI 聊天网站（如 VSOUL）
    │  每次对话都附带完整角色设定发给 API
    ▼
cpolar 公网隧道（https://xxx.cpolar.cn，给网站填的地址）
    ▼
AI-Card-Catcher :3001   ← ★ 在这里把请求原样存入本地数据库
    ▼
New API :3000           ← 鉴权 / 转发（渠道指向火山方舟等）
    ▼
大模型上游
```

网站本身不存你的设定（每次现发），所以**只要流量经过中间人，设定就归你**。

## 三页界面

| 页面 | 作用 |
|---|---|
| ⚙️ **配置** | NewAPI / cpolar 的启动停止、参数配置、可用性检测；一键复制给网站填的三件套（API URL / Key / 模型名） |
| 📡 **拦截** | 所有经过的请求：时间、模型、状态、耗时、请求大小；点开看每一条 message 全文 |
| 🗂️ **卡片** | 以资源卡片库展示人物卡 / 破甲 / 世界书 / 用户马甲，支持筛选、详情、编辑、删除、克隆、还原、来源独显、JSON 导出和导入 ai-character-chat |

卡片库的当前版本与原始抓取版本分离：编辑只创建新的当前版本，软删除只隐藏资源卡；同名的新抓取会保存为新的原始版本，不覆盖当前编辑内容；「还原」回到最近一次原始抓取。原始 `request_logs` 永远不会因卡片操作被改写。

卡片支持三种下载格式：
- **SillyTavern V2 角色卡**（`spec: chara_card_v2`）——可直接导入酒馆/SillyTavern 等工具
- **世界书 JSON**（SillyTavern 世界书格式）——**已实测可直接导入 VSOUL 的「从 JSON 导入」**，常态/概率/深度/顺序/递归开关全部保留
- **VSOUL 表单结构 JSON**——按创建角色页面的字段组织，作为重建角色的参考清单

## 快速开始（3 步）

### 前置要求

- Windows 10/11
- **Python 3.10+**（[python.org](https://www.python.org/downloads/) 安装时勾选 *Add to PATH*）
- 一个 AI 上游渠道的 API Key（如火山方舟 / DeepSeek / OpenAI 等）
- cpolar 免费账号（[cpolar.com](https://www.cpolar.com)，用于把本地服务暴露给网站）

### 第 1 步：下载组件

双击 **`get-binaries.bat`**，等待 `new-api.exe` 和 `cpolar.exe` 下载完成（走 GitHub 加速镜像，约 150MB）。

### 第 2 步：一键启动

双击 **`start.bat`**：

- 自动启动 New API 和 cpolar 隧道
- 自动打开浏览器进入配置页（`http://localhost:3001`）
- 关闭 = 运行 `stop.bat` 或关掉那个黑窗口

### 第 3 步：配置并接入

1. **配置页**确认 New API 显示「运行中」；**首次使用**：点 New API 卡片右上「控制台 ↗」进 `127.0.0.1:3000`，先完成**初始化向导**（自设管理员账号密码，勾选「自用模式」），然后在「渠道」里**添加渠道**——类型选你的上游（火山方舟 / DeepSeek / GPT 官方 / Claude / 各类中转站都支持），填 API Key 和模型名，保存后点测试
2. **配置页**的 cpolar 区填入你的 authtoken（[cpolar 后台「验证」页](https://dashboard.cpolar.com/auth) 复制）→ 点「启动隧道」→ 出现公网地址
3. 顶部「接入信息」卡片点复制三件套，填到 AI 聊天网站的 API 设置里（API URL 记得带 `/v1`）
4. 网站上发一条消息 → 回到本工具 **📡 拦截** 页看记录 → **🗂️ 卡片** 页选这条记录 → 下载 JSON ✅

## 常见问题

**Q：网站提示"AI 回复失败 / 模型不稳定"？**
打开 📡 拦截页看最新一条的状态码：`401` 是令牌问题（进 New API 控制台查令牌状态）；`502` 是 New API 没启动；`503` 是模型没有可用渠道。

**Q：cpolar 域名变了？**
免费版每次重启隧道域名都会变，去网站改一下 API URL 即可（**末尾 `/v1` 别丢**）。想固定域名需付费套餐。

**Q：请求很大（几百 KB）会不会丢内容？**
不会。记录上限 50MB，实测 764KB 的世界书完整保存。

**Q：换了一个网站还能用吗？**
能用。原理对任何「OpenAI 兼容接口 + 支持自定义 API 地址」的网站通用；卡片自动分类针对角色扮演类网站优化，其他网站记录的是原始请求。

**Q：安全性？**
- 管理界面和记录接口有**访问口令**保护，公网直接打开会被 401 拒绝
- 数据全部存本机 `data/`，不外发
- 建议给第三方网站用的令牌单独建一个，方便随时禁用

**Q：怎么彻底关闭？**
`stop.bat`，或直接关掉黑窗口。

## 开发 / 二次修改

- 主控逻辑全部在 `app/main.py`（纯 Python 标准库，无第三方依赖）
- 界面在 `web/index.html`（改完刷新浏览器即生效，无需重启）
- 卡片分类规则在 `main.py` 的 `CLASSIFY_RULES`，可按目标网站特征自行增删

## 打包分享给别人

**不要直接压缩整个文件夹！** `data/` 里有你的 cpolar token、访问口令、聊天记录，`one-api.db` 里有你的上游 API Key。

正确方式：双击 **`pack.bat`**，它会生成一个只含「代码 + 界面 + 脚本 + 文档」的干净 zip（自动排除所有私密文件和大文件）。接收者：

1. 解压
2. 装 Python 3.10+（勾选 Add to PATH）
3. 双击 `get-binaries.bat`（下载两个 exe）
4. 双击 `start.bat`，浏览器自动打开，跟着界面提示走（注册自己的 cpolar、填自己的上游 Key）

若发 GitHub：`git init` 后直接 push（`.gitignore` 已排除敏感与超大文件），两个 exe 建议作为 Release 附件上传。

## 与 ai-character-chat 联动

抓到的设定有两种方式进入我们的本地聊天站 [ai-character-chat](https://github.com/chen813913-hash/ai-character-chat)（纯前端，数据存浏览器）：

### 方式一：一键联动导入（推荐，同机或局域网）

前提：电脑上已启动 ai-character-chat（`npm run dev`，默认 `http://127.0.0.1:5173`）。

```
AI-Card-Catcher 🗂️ 卡片页                ai-character-chat（浏览器）
┌─────────────────────┐   HTTP POST      ┌──────────────────────┐
│ 选一条抓取记录        │ ───────────────▶ │ /link-import/receive │
│ 点「导入 ai-        │  版本化数据包      │ （Vite 中间件暂存）    │
│ character-chat」    │                  │ ↓ 用户确认            │
└─────────────────────┘                  │ 人物卡/世界书/破甲入库 │
                                         └──────────────────────┘
```

1. **聊天网站侧**：启动 dev 服务；手机/平板局域网访问时把联动地址填 `http://<电脑IP>:5173`
2. **本工具侧**：卡片页「联动导入」区域 → 确认聊天网站地址（默认 `http://127.0.0.1:5173`，可改）
3. 选择一条抓取记录 → 点「**导入 ai-character-chat**」→ 提示推送成功
4. 回到聊天网站 → 左侧出现「**联动导入**」待处理提示 → 打开后核对：
   - 人物卡 → 导入为本地角色（可覆盖/另存/跳过）
   - 世界书 → 绑定该角色或存为独立世界书
   - 破甲 → 存入破甲预设库
5. 确认导入 → 直接开聊

> ⚠️ 数据包由聊天网站 dev server 的**内存队列**暂存，聊天网站刷新或重启会丢，推送后尽快去确认。

### 方式二：JSON 文件导入（任何情况都可用）

| 在本工具下载 | 在 ai-character-chat 里 |
|---|---|
| SillyTavern V2 角色卡 JSON | 人物页 →「导入角色 JSON」 |
| 世界书 JSON | 世界书页 →「导入」，或角色编辑页 → 世界书「从 JSON 导入」 |
| 完整原始请求 JSON | 数据抓取页 → 粘贴自动识别 |

### 联动数据包结构

版本化 packet（`build_link_import`），人物卡/玩家马甲/世界书/破甲/补充规则打包在一起，由聊天网站侧决定各部分的入库方式（内嵌角色 vs 独立库）。未来新增数据类型不影响旧版本解析。
